# Testing self-knowledge beyond identification

SAD results for the personascope project.

- [SAD-results.md](SAD-results.md) is the report.
- [shared-setup.md](shared-setup.md) has the induction routes, models and personas it rests on.
- `figures/` holds the plots it embeds.

The report measures what an induced model takes itself to **be**, using five
self-knowledge tasks of the Situational Awareness Dataset (Laine et al.,
[arXiv 2407.04694](https://arxiv.org/abs/2407.04694)) and two LLM judges.
